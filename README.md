# Rooted — Man Matters adherence companion

A mobile-first demo concept for helping users stay consistent through a six-month hair-care routine. Includes a daily routine checklist, scalp self-check, photo journal, progress timeline, shedding-phase support, and illustrative refill nudges.

## Run locally

Open `index.html` in a browser. This prototype uses fictional demo data and browser local storage; it has no backend or checkout.

## Scope

Rooted supports routine adherence and self-observation. It does not diagnose scalp conditions, assess a Norwood stage, recommend treatment changes, or replace a clinician. Follow the plan provided by your clinician and product label; contact your clinician about side effects or treatment questions.

This is an independent concept prototype and is not an official Man Matters product.
